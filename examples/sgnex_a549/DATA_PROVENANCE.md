# SG-NEx A549 example: data provenance

`SGNex_A549_directRNA_replicate6_run1.doradov300.sup.mt.sorted_flnc.ssc` is an alignment-derived, MT-only SSC input prepared from the public SG-NEx A549 direct-RNA resource. It contains endpoint-coordinate records only; no FASTQ, BAM, raw signal or additional SG-NEx sample is included in this repository.

Source resource: SG-NEx data, accessed through the AWS Open Data Registry. Please cite Chen et al., *Nature Methods* 22, 801–812 (2025), doi:10.1038/s41592-025-02623-4, and state that the SG-NEx data were accessed at `registry.opendata.aws/sg-nex-data`.

The SSC is included solely as a runnable mtfind example. It is not an official SG-NEx distribution format and does not replace the source resource or its documentation.
