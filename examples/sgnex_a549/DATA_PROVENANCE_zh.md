# SG-NEx A549 示例：数据来源

`SGNex_A549_directRNA_replicate6_run1.doradov300.sup.mt.sorted_flnc.ssc` 是由公开 SG-NEx A549 direct-RNA 资源整理得到的、仅含 MT 比对端点的 SSC 输入。该仓库只包含端点坐标记录；不包含 FASTQ、BAM、原始信号或其它 SG-NEx 样本。

原始资源为 AWS Open Data Registry 上的 SG-NEx 数据。使用时请引用 Chen 等人在 *Nature Methods* 22, 801–812 (2025) 发表的论文，doi:10.1038/s41592-025-02623-4，并注明 SG-NEx 数据访问自 `registry.opendata.aws/sg-nex-data`。

该 SSC 仅用于运行 mtfind 示例；它不是 SG-NEx 官方发布格式，也不能替代原始资源及其说明。
